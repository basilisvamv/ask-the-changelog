# Ask the Changelog

Ask the Changelog watches the changelog pages of AI companies. When a new announcement appears, it scores it against the keywords the user picks, shows it on the page, and sends an alert when the match is high.

The project was built for the **"The Web Is Your Real-Time Database"** challenge by Context.dev, at Junction 2026.

## What it does

- **Extraction:** each company is checked through the Context.dev Scrape API (`POST /v1/web/scrape`). The page is returned as JSON that follows our schema: date, title, category, a short English summary, and a link.
- **Change detection:** each check is compared with the previous snapshot. The title and date identify an announcement. Older announcements are never treated as new.
- **Scoring:** each announcement gets a level (high, medium, low or none), based on how many of the user's keywords match.
- **Recommendation:** for each company, the best-matching announcement is shown. The app says which company matches the keywords best, without judging which AI is better.
- **Explanation:** for the top announcements, and for any announcement the user asks about, the Context.dev Answers API gives a short explanation and its sources.
- **Automatic checks:** the server checks every company every 60 minutes. You can change this with `AUTO_CHECK_MINUTES`.

## Running it

You need Node.js 22 or newer.

1. Install the dependencies:
   ```
   npm install
   ```
2. Create a `.env` file by copying `.env.example`, and add your Context.dev key:
   ```
   CONTEXT_DEV_API_KEY=your_key_here
   PORT=3000
   ```
3. Start the server:
   ```
   npm start
   ```
4. Open `http://localhost:3000`.

For development with automatic restarts, run `npm run dev`. Run the tests with `npm test`.

## Structure

```
src/
  server.js     Express server, routes and automatic checks
  extract.js    Context.dev Scrape call and raw response storage
  diff.js       normalisation, extraction checks and new-announcement detection
  relevance.js  keywords, relevance levels and ranking
  answers.js    Context.dev Answers call for explanations
  links.js      checks that a link belongs to the company's domain
  limits.js     rate limit for explanations and a lock per company
  store.js      storage in JSON files
public/
  index.html    the user interface (no framework)
config/
  companies.json   companies and their URLs
  schema.json      the schema we ask Context.dev to return
test/           tests with node:test
```

Data is stored in the `data/` folder: `raw/` (the raw response), `snapshots/` (the latest state of each company), `changes.json` (new announcements) and `profile.json` (the user's keywords).

## Limitations

- The summaries are generated by AI and are not checked automatically. This is why every announcement links to its source.
- A new announcement is detected only when it has a date. Announcements without a date are ignored.
- If a check finds more than 10 new announcements at once, the app assumes the page layout changed. It does not report them and starts a new baseline.
- - Context.dev charges credits for each check. The automatic check runs for every company every 60 minutes, so the cost adds up over time.
